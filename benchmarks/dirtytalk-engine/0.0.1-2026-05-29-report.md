## Scenarios

- `signal-set-notify` — Signal `.value` set + synchronous notify, 1 subscriber (2,000,000 sets)
- `channel-broadcast` — DirtyChannel mark+flush, 100 subscribers all interested (50,000 marks)
- `channel-selective` — DirtyChannel mark+flush, 1000 subscribers, 1 intersects per mark (10,000 marks)
