<SectionBreak label="§ why blac" dotSize="7px" dotOpacity="0.2" />

<RisoHeading as="h2" intensity="subtle">
  Chaos resolving into calm
</RisoHeading>

State changes are messy by nature. BlaC's job is to let you write the messy
part plainly and read it back as something calm and predictable.

- **Read state like a plain object.** No selectors to memoize, no boilerplate
  to wire. Touch what you need; BlaC tracks it for you.
- **Only what changed re-renders.** Each `useBloc` consumer gets its own
  dependency tracking, so a change to one slice never wakes a component that
  never read it.
- **Type-safe to the edges.** Inference flows from your state shape through to
  every consumer — no casts, no `any`, no surprises.
