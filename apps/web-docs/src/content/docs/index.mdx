## Here. This is all of it.

A class holds your state and the methods that change it. One hook connects it
to React. No store setup, no provider tree, no action types.

```tsx twoslash
import React from 'react';
import { Cubit } from '@blac/core';
import { useBloc } from '@blac/react';

class CounterCubit extends Cubit<{ count: number }> {
  constructor() {
    super({ count: 0 });
  }
  increment = () => this.emit({ count: this.state.count + 1 });
}

function Counter() {
  const [state, counter] = useBloc(CounterCubit);
  return <button onClick={counter.increment}>Count: {state.count}</button>;
}
```

## Less wiring, fewer re-renders

<CardGrid>
  <Card title="Touch it, you're subscribed" icon="magnifier">
    Read `state.user.name` and the component re-renders only when that value
    changes. No selectors, no memoization. [How tracking
    works](/react/dependency-tracking/)
  </Card>
  <Card title="Logic lives in typed classes" icon="pencil">
    Methods are your actions, `this.state` is the source of truth, and `emit`,
    `update` and `patch` change it. [Core concepts](/guide/concepts/)
  </Card>
  <Card title="Cross-bloc getters" icon="approve-check">
    A getter can read another bloc's state, and components reading it re-render
    when either bloc changes. [Bloc communication](/core/bloc-communication/)
  </Card>
  <Card title="Lifecycle you don't manage" icon="rocket">
    Instances are shared and ref-counted: the first consumer creates one, the
    last to unmount disposes it. [Instance
    management](/core/instance-management/)
  </Card>
  <Card title="Batteries, opt-in" icon="setting">
    [DevTools](/plugins/devtools/), [persistence](/plugins/persistence/),
    [logging](/plugins/logging/), [testing utilities](/testing/overview/) and
    [SSR isolation](/integrations/ssr/) attach without touching your logic.
  </Card>
  <Card title="Works outside React" icon="puzzle">
    The core is framework-agnostic. `watch()` a bloc from a router, a game loop
    or a test. [Outside React](/integrations/outside-react/)
  </Card>
</CardGrid>
