# BlaC Documentation

VitePress documentation site for BlaC.

## Structure

```
guide/          Getting started, concepts, introduction
core/           Core library reference (Cubit, registry, watch, types, plugins, etc.)
react/          React integration (useBloc, tracking, performance)
plugins/        Official plugins (logging, devtools, persistence)
integrations/   SSR, Next.js, Remix, React Native, outside React
```

## Development

```bash
pnpm dev
```

## Building

```bash
pnpm build
```

## Preview

```bash
pnpm preview
```
